غراب ليبيا — ملفات الموقع
=========================
- index.html: صفحة الموقع.
- style.css: تنسيق التصميم المتجاوب.
- assets/: صورة الخلفية المستخدمة.

طريقة النشر على GitHub Pages:
1. فك ضغط الملف.
2. ارفع index.html وstyle.css ومجلد assets إلى جذر المستودع.
3. احفظ التغييرات (Commit changes).
4. من Settings > Pages تأكد من النشر من main / (root).

ملاحظة: هذا تصميم تعريفي فقط. لا يحتوي على ملفات استغلال أو GoldHEN ولا يفعّل الجلبريك تلقائيًا.
التاريخ المعروض 1.11.2026 كما طلب المستخدم.
